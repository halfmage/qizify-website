# AZAV online providers: target list (QCG / Bildungsgutschein)

Researched 2026-11-14 from each provider's own website. "Not shown" = not stated on their page. Before outreach, check each course's approval in KURSNET. No contact persons collected yet. Outreach follows the meeting-invite rule (no pitch, no demo link).

## Why this segment

- Funded courses (§ 82 SGB III / QCG, Bildungsgutschein) pay approved providers per participant. Company-specific software training is not fundable, so LearnSlice earns via providers that run their approved courses on it.
- Most providers run "100 % live online" on Zoom or a thin platform. The gap is self-paced practice and exam rehearsal between live sessions.
- § 34a check: funded prep courses run 180+ clock hours (BFW München 240 UE, WBS 41 days), well above the 120-hour minimum. § 34a GewO restricts who the company may employ but doesn't oblige it to run training, so the QCG exclusion probably doesn't apply. WBS advertises QCG for § 34a. Not officially confirmed: ask an Arbeitgeber-Service.
